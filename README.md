# AI Business Copilot

AI-powered Business Intelligence Platform built using Streamlit, Groq LLM, Plotly and Prophet.

## Features

- Upload CSV / Excel
- KPI Dashboard
- AI Insights
- Chat with Data
- SQL Generator
- Forecasting
- Business Reports
- Advanced Analytics
- Auto Dashboard Builder

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Prophet
- Groq LLM

## Run Locally

pip install -r requirements.txt

streamlit run app.py
